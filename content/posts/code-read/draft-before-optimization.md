## 背景

AI时代，工程师的决策能力变得愈发重要。因为很多执行的工作基本可以交由AI解决，所以更多的工作内容转移到如何设计和决策。如何发现一个真的问题，并设计出一个方案（这一步甚至绝大情况下也不需要了），那么难点就是如何决策。决策的难点就是取舍，因为只有需要舍弃才需要选择，做好它的必然要求是了解各个方案背后的优缺点。方向对了，最后的结果可能会好，否则AI写的再快也没有用。

另外一个方面是设计。如何在变化中找到不变的东西会变得愈发重要。代码生产速度加快后，人类应该没有精力再去一行行的精度各种代码，代码本身变得不再重要，如何组织这些代码变得更关键。因为设计是用来解决具体的问题，合理的设计可以解决一类问题，否则就会陷入过度设计。特别在AI时代，软件形态发生了很大的变化。比如要求从端到端的处理各种变化的问题，这里面意图识别，上下文管理，工具调用，权限等都有难点。这些问题哪怕你直接问AI 可能也很难高质量地解决，但是目前已经有不少coding agent可以很好地帮助用户完成任务。但这里面的设计，我认为很多是可以学习的，因此，我想重新写一篇文章，结合AI背景下，我们如何高效地阅读源码。


## 正文

首先，和很多事一样，在做之前我们一定要有一个目标。对于我来说，终极目标是将提升我的工程设计和决策能力，然后可以更好地解决现实世界中的问题。所以，读代码并不是目的，而是提炼出里面有价值的设计。

阅读源码的核心原则：
不要试图理解所有的代码，而是思考设计决策背后的Why
1.建立全局地图
    为什么要建立全局地图？人天生就有将知识分区的概念。比如学习使用的工具，思维导图以及在收拾家里物品时，都习惯将物品分区。图书馆，商场大楼都会按照类别对书籍和门店分类置放。
    人的大脑是模式匹配器，不是解释器。
    模式匹配器。快速识别分类，并划分模块，跳过细节直达本质。
    解释器。逐行读取指令，不跳过任何一步，顺序执行。
    科学上有几个经典的实验可以佐证。
    1.象棋实验
    让象棋高手和新手同时复盘棋局。
    -如果真实棋局。高手能够复原80%，新手只能复原30%
    -如果随机摆放。高手和新手的水平差不多。
    这证明了不是高手的记忆更好，而是能够将棋局识别为一种模式的组合。而随机摆放则没有规律，对两者都一样。
    2.阅读也是一种模式匹配
    有没有这样一种感觉，阅读文章的时候，有时候哪怕每一字都仔细看过，但还是不了解其中的含义。而有时只是扫一眼就领悟了其中的意义。这真命了我们阅读文章并不是靠逐字解释，而是理解其中最可能的含义。
    3.系统一，系统二。
    丹尼尔卡尼曼将人脑理解力分为两类，系统一，快速地，分营。系统2，
    这里的系统一就是模式匹配，轻松，快速，可以持续长时间。
    系统二是，高耗能，容易疲劳。
  ┌──────┬────────────────────────┬────────────────────────┐
  │      │ 系统 1（快，模式匹配） │ 系统 2（慢，逐步推理） │
  ├──────┼────────────────────────┼────────────────────────┤
  │ 速度 │ 毫秒级                 │ 秒到分钟级             │
  ├──────┼────────────────────────┼────────────────────────┤
  │ 耗能 │ 低                     │ 高，容易疲劳           │
  ├──────┼────────────────────────┼────────────────────────┤
  │ 容量 │ 并行处理               │ 严格串行               │
  └──────┴────────────────────────┴────────────────────────┘

2.聚焦关键路径
    为什么要聚焦关键路径？
    二八定律。系统百分之八十的任务都集中在百分之15的流程中。
    走完一个系统的执行路径，一般都包括，序列化，校验，业务逻辑，持久化，错误处理等，这些就是系统的骨架
3.带着问题读
    认知心理学有个概念叫生成效应（Generation Effect），指人们更容易记住自己主动思考生成的信息，也非被动地接受。了解为什么这样做比知道怎么样做更加容易留下印象
    -扩展性。我要加一个功能该如何做。
    -trade-off 为什么选A方案而不选B。
    -容错机制。如果服务/依赖挂了会怎么样。
    -耦合度。某个模块拿出去会怎么样。
    以上四点就是在模拟架构师的日常工作，

4.输出和反馈。
    人脑的遗忘曲线是残酷的，假如不把它表达出来，往往很容易就遗忘。而且表达的过程就是自我辩论，最终形成模块化知识点。因为不成系统化的知识别人也很难裂解
